## 📌 Tentang Proyek

Website PLN yang ada saat ini memiliki tampilan yang kurang modern dan navigasi yang kurang intuitif. Proyek ini adalah **redesain konseptual** yang bertujuan untuk:

- Meningkatkan pengalaman pengguna (UX) yang lebih bersih dan modern
- Mempercepat akses layanan utama (tagihan, token, gangguan)
- Membuat tampilan yang fully responsive di semua perangkat
- Menampilkan informasi operasional secara real-time dan visual

---

## 🛠️ Teknologi

| Teknologi | Kegunaan |
|-----------|----------|
| HTML5 | Struktur halaman semantik |
| CSS3 | Styling, Flexbox, Grid, animasi |
| Vanilla JavaScript | Interaksi, scroll animation, counter |
| Google Fonts | Plus Jakarta Sans & Syne |

Tidak menggunakan framework — murni HTML, CSS, dan JavaScript vanilla.

## ✨ Fitur Website

- **Navbar sticky** dengan efek blur saat scroll
- **Hero section** dengan data operasional real-time (animasi counter)
- **Quick access** 6 layanan utama dengan tooltip
- **Kartu layanan** dengan hover effect dan ripple
- **Stats banner** dengan animasi angka
- **Section energi terbarukan** dengan poin-poin komitmen
- **Peta gangguan** informatif
- **Promo PLN Mobile** dengan stat card
- **Berita terbaru** 3 kartu artikel
- **Testimoni pelanggan**
- **Footer lengkap** dengan link navigasi
- **Back to top button** animasi
- **Toast notification** interaktif
- **Mobile responsive** (375px – 1440px)
- **Hamburger menu** dengan animasi

---

## 📱 Responsivitas

| Breakpoint | Layout |
|------------|--------|
| ≥ 1024px | Desktop — 2 kolom, full navbar |
| 768px – 1024px | Tablet — grid menyesuaikan, hamburger menu |
| ≤ 480px | Mobile — single kolom, stacked layout |
